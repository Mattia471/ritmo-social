# Versioni e provenienza dei commit

La repository è stata creata da **snapshot del codice** prodotti durante il collaudo. Gli archivi disponibili erano:

| Tag ricostruito | Snapshot |
|---|---|
| `v0.1.0` | MVP iniziale, demo mobile |
| `v0.2.0` | Rebrand e mappa eventi |
| `v0.2.1` | Correzione zoom input su iPhone |
| `v0.2.2` | Campi data/ora iOS |
| `v0.3.0` | Revisione home, mappa e chat mobile |
| `v0.4.0` | Wizard evento, cluster mappa, sticky RSVP |
| `v0.4.1` | Test di regressione, deduplicazione e capienza |

**Importante:** gli ZIP non contenevano alcuna directory `.git`. I commit e i tag archiviati qui sono stati generati in ordine di versione per facilitare la navigazione fra snapshot. Sono nuovi commit e **non rappresentano lo storico Git originale**, né pretendono di riprodurre l'autore o il timestamp dei commit originari. Se in futuro emergerà una vecchia repository con il vero storico, andrà conservata e considerata autoritativa; questa cronologia potrà essere importata separatamente senza riscriverla.
